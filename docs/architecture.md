# 类脑认知架构设计文档

## 1. 设计理念

本项目旨在构建一个模拟大脑信息处理机制的认知架构，融合神经科学、认知科学和人工智能的研究成果，实现一个具有感知、记忆、学习、决策和情绪调节能力的类脑系统。

### 1.1 核心原则
- **生物启发**: 基于真实大脑的结构和机制设计
- **分层处理**: 从低级感知到高级认知的分层加工
- **并行分布**: 信息在多个脑区并行处理
- **动态调制**: 神经调质系统调节信息加工
- **可塑性**: 突触连接和记忆强度可随经验改变

## 3. 三层神经网络

### 3.1 感官层 (Sensory Layer)

**功能**: 接收外部刺激，进行初步的感官信息处理

**特性**:
- **多模态处理**: 支持多种感官模态（视觉、听觉、触觉等）
- **拓扑组织**: 每种模态对应特定的神经元群
- **感官适应**: 对持续刺激的响应逐渐减弱
- **增益控制**: 注意力调节感官增益

**参数**:
- 神经元数量: 100
- 模态数量: 5（默认）
- 适应速率: 0.01/步
- 输入放大: 5.0倍

**神经机制**:
- 输入电流 → 膜电位积分 → 脉冲发放
- 侧抑制增强对比度
- 适应机制防止饱和

### 3.2 联想层 (Association Layer)

**功能**: 跨模态信息整合，概念形成，联想记忆

**特性**:
- **概念集群**: 相关神经元形成概念表征
- **Hebbian学习**: 同时激活的神经元连接增强
- **循环连接**: 层内循环维持活动模式
- **记忆交互**: 与记忆系统双向交互

**参数**:
- 神经元数量: 150
- 概念阈值: 0.3
- Hebbian学习率: 0.01
- 最大权重: 2.0

**神经机制**:
- 吸引子动力学
- 模式完成
- 自联想记忆

### 3.3 决策层 (Decision Layer)

**功能**: 动作选择，决策制定，行为输出

**特性**:
- **赢家通吃 (WTA)**: 最强激活的动作被选中
- **侧抑制**: 神经元之间相互抑制
- **强化学习**: 基于奖励调整决策偏好
- **置信度**: 评估决策的确定性

**参数**:
- 神经元数量: 8
- 决策阈值: 0.3
- 侧抑制强度: 0.5
- 学习率: 0.1

**神经机制**:
- 竞争选择
- 置信度计算
- 探索-利用平衡

## 4. 三级记忆系统

### 4.1 感官缓存 (Sensory Buffer)

**功能**: 短时保存原始感官信息，供后续加工

**特性**:
- 大容量但快速衰减
- 模态特异性
- 前注意加工
- 容量: 15个记忆项
- 持续时间: ~500ms

**机制**:
- 时间衰减: 记忆强度随时间指数下降
- 容量限制: 超出容量时最早的记忆被替换
- 转移阈值: 强度足够的记忆转移到短期记忆

### 4.2 短期记忆 (Short-Term Memory)

**功能**: 工作记忆，当前意识可及的信息

**特性**:
- 有限容量（7±2法则）
- 主动维持
- 易受干扰
- 容量: 20个记忆项
- 持续时间: 秒级到分钟级

**机制**:
- 复述强化: 激活复述增强记忆保持
- 干扰: 新信息干扰旧记忆
- 巩固: 重要记忆转移到长期记忆

### 4.3 长期记忆 (Long-Term Memory)

**功能**: 持久存储知识和经验

**特性**:
- 大容量
- 相对持久
- 语义网络结构
- 激活扩散
- 容量: 500个记忆项

**机制**:
- 巩固: 从短期记忆转移，需要时间和重复
- 提取: 线索匹配，激活扩散
- 再巩固: 提取后重新巩固
- 遗忘: 逐渐衰减，干扰导致遗忘

### 4.4 记忆转移机制

```
感官刺激 → 感官缓存
              ↓ (强度阈值 + 概率转移)
           短期记忆
              ↓ (巩固概率 + 多巴胺调节)
           长期记忆
              ↑ (线索提取 + 激活扩散)
           短期记忆
```

**转移规则**:
1. **感官→短期**: 强度 > 0.5 且 随机概率 < 0.3
2. **短期→长期**: 巩固概率 0.01/步，多巴胺增强
3. **长期→短期**: 线索相似度 > 0.3，激活扩散

## 5. 胶质细胞系统

### 5.1 星形胶质细胞 (Astrocytes)

**功能**: 突触调节、离子稳态、能量代谢、钙波传播

**特性**:
- **钙信号**: 细胞内钙浓度变化，钙波传播
- **突触调制**: 调节突触传递效率
- **钾缓冲**: 吸收胞外钾离子，维持离子平衡
- **递质回收**: 回收谷氨酸等神经递质
- **缝隙连接**: 细胞间形成网络，钙波传播

**参数**:
- 数量: 50个（约神经元数量的50%）
- 钙基线: 0.1
- 钙波阈值: 0.5
- 谷氨酸摄取率: 0.1

**机制**:
- 神经元活动 → 谷氨酸/钾释放 → 星形胶质钙升高
- 钙升高 → 释放胶质递质 → 反馈调节突触
- 钙波通过缝隙连接在胶质网络中传播

### 5.2 少突胶质细胞 (Oligodendrocytes)

**功能**: 髓鞘形成、传导速度调节、轴突营养支持

**特性**:
- **髓鞘化**: 包裹轴突，形成髓鞘
- **活动依赖可塑性**: 高活动轴突髓鞘增厚
- **传导速度**: 髓鞘厚度影响传导速度
- **营养支持**: 为轴突提供能量

**参数**:
- 数量: 20个
- 髓鞘产生率: 0.01
- 可塑性阈值: 0.3

**机制**:
- 轴突高活动 → 髓鞘增厚 → 传导加速
- 能量不足 → 髓鞘退化 → 传导减慢

### 5.3 小胶质细胞 (Microglia)

**功能**: 免疫监视、突触修剪、神经营养、炎症响应

**特性**:
- **监测状态**: 持续监测周围环境
- **激活状态**: 响应损伤或异常
- **突触修剪**: 修剪弱的突触，优化连接
- **神经营养**: 释放生长因子
- **炎症反应**: 释放细胞因子

**状态**:
- surveying (监测): 正常状态，突起动态延伸
- activated (激活): 响应损伤，炎症水平上升
- phagocytic (吞噬): 吞噬清除碎片

**参数**:
- 数量: 10个
- 修剪阈值: 0.2
- 监测半径: 5.0

### 5.4 胶质-神经元交互

```
神经元活动 → 谷氨酸/钾释放 → 星形胶质钙升高
                ↑                    ↓
         突触调制 ← 胶质递质释放 ← 钙波传播

轴突活动 → 少突胶质 → 髓鞘增厚 → 传导加速

弱突触 → 小胶质监测 → 突触修剪 → 网络优化
损伤 → 小胶质激活 → 炎症反应 → 修复
```

**交互机制**:
1. **星形胶质-突触**: 三方突触（突触前+突触后+胶质细胞）
2. **少突胶质-轴突**: 活动依赖的髓鞘可塑性
3. **小胶质-突触**: 突触修剪和重塑
4. **胶质网络**: 缝隙连接介导的细胞间通信

## 6. 思考系统

### 6.1 思考空间 (Thought Space)

**功能**: 全局工作空间，意识内容的广播与整合

**理论基础**: 全局工作空间理论 (Global Workspace Theory)

**特性**:
- **有限容量**: 7±2个思维内容（工作记忆容量）
- **全局广播**: 意识内容被广播到所有子系统
- **思维竞争**: 候选思维竞争进入意识
- **注意力选择**: 注意力偏向影响思维选择
- **思维流**: 思维内容的连续流转

**参数**:
- 容量: 7个思维内容
- 思维转换概率: 0.3
- 思维速率: 可调

**机制**:
```
候选思维池 → 竞争选择 → 全局广播 → 子系统接收
                ↑                    ↓
                └── 注意力偏向 ──────┘
```

**思维类型**:
- PERCEPTUAL (感知性): 来自感官输入
- MEMORY (记忆性): 来自记忆提取
- EMOTIONAL (情绪性): 来自情绪状态
- ABSTRACT (抽象): 内部生成的抽象思维
- GOAL_DIRECTED (目标导向): 目标驱动的思维
- SELF_REFERENTIAL (自我参照): 关于自我的思维
- IMAGERY (心理意象): 想象/心理意象

### 6.2 思考记忆 (Thought Memory)

**功能**: 记录和管理思维过程的记忆系统

**特性**:
- **思维序列记忆**: 记录思考的先后顺序
- **思维情节记忆**: 完整的思考片段/情节
- **元记忆**: 对自己思维能力的认知
- **思维模式识别**: 识别思维模式和习惯
- **思维回溯**: 回溯思考过程

**结构**:
- 当前思维序列: 正在进行的思维流
- 思维情节库: 存储的完整思维片段
- 元记忆知识: 关于思维的自我认知

**参数**:
- 最大情节数: 100
- 每情节最大思维数: 50

**元记忆维度**:
- thinking_speed: 思维速度自评
- memory_confidence: 记忆自信度
- problem_solving: 问题解决能力
- creativity: 创造力自评

### 6.3 思考感官 (Thought Sensory)

**功能**: 元认知感知系统，监测和感知自身的思考状态

**理论基础**: 元认知理论 (Metacognition)

**感知维度**:
- **思维流畅度 (fluency)**: 思考是否顺畅
- **认知负荷 (cognitive_load)**: 脑力消耗程度
- **确定性 (confidence)**: 对思维内容的确信度
- **熟悉感 (familiarity)**: 内容是否熟悉
- **知道感 (feeling_of_knowing)**: 感觉自己知道
- **舌尖效应 (tip_of_tongue)**: 差点想起来
- **心理努力 (mental_effort)**: 心理努力程度
- **思维清晰度 (thought_clarity)**: 思维清晰程度

**反馈信号**:
- **顿悟时刻 (aha_moment)**: 突然理解/顿悟
- **冲突检测 (conflict_detection)**: 思维间的冲突
- **错误监测 (error_monitoring)**: 检测思维错误
- **进度监测 (progress_monitoring)**: 目标进度感知

**功能**:
- **内省 (introspection)**: 观察自身思维过程
- **元认知判断**: 对自己思维的判断
- **认知反馈**: 调节思考策略

**状态**:
- 正常思考: 普通的思维感知
- 内省中: 主动观察自己的思维

### 6.4 思考系统整合

```
感官输入 → 感知性思维 ─┐
记忆提取 → 记忆性思维 ─┤
情绪状态 → 情绪性思维 ─┼→ 候选思维池 → 思考空间 → 全局广播
内部生成 → 抽象思维 ──┘        ↑              ↓
                           注意力偏向     思考记忆
                                ↓              ↓
                              思考感官 ←───────┘
                            (元认知感知)
```

**与其他系统的交互**:
1. **感官→思考**: 感知内容转化为思维
2. **记忆→思考**: 记忆提取进入思维
3. **情绪→思考**: 情绪状态影响思维内容
4. **注意力→思考**: 注意力选择思维内容
5. **思考→联想层**: 思维反馈影响神经活动
6. **思考→思考记忆**: 思维过程被记录
7. **思考→思考感官**: 思维被元认知感知

## 7. 三大调制系统

### 7.1 情绪内核 (Emotional Core)

**功能**: 评估刺激的情绪意义，调节认知加工

**模型**: 效价-唤醒度二维模型
- **效价 (Valence)**: 正性 ↔ 负性 (-1 ~ 1)
- **唤醒度 (Arousal)**: 平静 ↔ 激动 (0 ~ 1)

**基本情绪**:
- joy (快乐): 高效价，中唤醒
- sadness (悲伤): 低效价，低唤醒
- anger (愤怒): 低效价，高唤醒
- fear (恐惧): 低效价，高唤醒
- surprise (惊讶): 中性效价，高唤醒
- disgust (厌恶): 低效价，中唤醒
- neutral (中性): 中间状态

**功能**:
- 情绪评估: 快速评估刺激的情绪意义
- 情绪记忆: 情绪性事件记忆更牢固
- 注意偏向: 情绪一致性注意增强
- 决策影响: 情绪影响风险偏好

### 7.2 注意力调制 (Attention Modulator)

**功能**: 选择性增强相关信息的加工

**两种注意系统**:
1. **自下而上 (Bottom-up)**: 刺激驱动的显著性捕获
2. **自上而下 (Top-down)**: 目标驱动的注意分配

**机制**:
- 增益调制: 注意增强神经元响应增益
- 竞争选择: 注意资源有限，相互竞争
- 转移机制: 注意焦点的动态转移

**参数**:
- 注意强度: 0 ~ 2.0
- 焦点大小: 可调
- 转移速度: 可调

### 7.3 多巴胺奖励系统 (Dopamine Reward System)

**功能**: 奖励预测，强化学习，动机调节

**核心机制**: 奖励预测误差 (RPE)
```
RPE = 实际奖励 - 预测奖励
```

**功能**:
- **价值学习**: 学习刺激的奖励价值
- **强化学习**: 强化导致奖励的行为
- **动机调节**: 多巴胺水平影响动机水平
- **记忆增强**: 多巴胺增强记忆巩固

**参数**:
- 基础多巴胺: 0.3
- 学习率: 0.1
- 衰减速率: 0.05/步
- 最大水平: 1.0

## 8. 系统整合

### 8.1 信息流

**前馈通路**:
```
外部刺激 → 感官层 → 联想层 → 决策层 → 行为输出
```

**反馈通路**:
```
决策层 → 联想层 (自上而下注意)
长期记忆 → 联想层 (记忆提取)
```

**调制通路**:
```
情绪 → 注意力 → 感知增益
多巴胺 → 学习率 → 突触可塑性
情绪 → 记忆巩固 → 长期记忆
```

### 8.2 系统交互

**记忆-网络交互**:
- 编码: 网络活动模式存入记忆
- 提取: 记忆模式反馈到网络
- 巩固: 重复激活增强记忆

**情绪-认知交互**:
- 情绪影响注意分配
- 情绪影响记忆强度
- 情绪影响决策偏好

**多巴胺-学习交互**:
- 多巴胺调节突触可塑性
- 多巴胺增强记忆巩固
- 多巴胺驱动强化学习

**胶质-神经元交互**:
- 星形胶质细胞调节突触传递
- 钙波传播实现胶质网络通信
- 少突胶质细胞调节传导速度
- 小胶质细胞修剪优化突触连接

**思考-神经网络交互**:
- 感官/记忆活动转化为思维内容
- 思维内容反馈影响联想层活动
- 注意力选择决定哪些思维进入意识
- 元认知感知监测思维状态

### 8.3 时间动态

**快速过程** (毫秒级):
- 感官处理
- 脉冲传播
- 注意转移

**中速过程** (秒级):
- 工作记忆
- 情绪变化
- 决策形成

**慢速过程** (分钟到小时级):
- 记忆巩固
- 突触可塑性
- 长期学习

## 9. 数学模型

### 9.1 脉冲神经元 (LIF模型)

**膜电位动力学**:
```
τ_m * dV/dt = V_rest - V(t) + I(t) * R
```

其中:
- V(t): 膜电位
- V_rest: 静息电位
- I(t): 输入电流
- τ_m: 膜时间常数
- R: 膜电阻

**发放条件**:
```
如果 V(t) ≥ V_threshold:
    产生脉冲
    V(t) → V_reset
    进入不应期
```

### 9.2 记忆动力学

**记忆衰减**:
```
strength(t) = strength_0 * exp(-t / τ_decay)
```

**记忆巩固**:
```
d(strength)/dt = consolidation_rate * dopamine_level
```

**激活扩散**:
```
activation_i = Σ_j (activation_j * weight_ij)
```

### 9.3 学习规则

**Hebbian学习**:
```
Δw_ij = η * a_i * a_j
```

其中:
- η: 学习率
- a_i, a_j: 突触前后神经元活动

**强化学习**:
```
Δvalue = α * (reward - predicted_value)
```

其中:
- α: 学习率
- reward: 实际奖励
- predicted_value: 预测奖励

### 9.4 注意调制

**增益调制**:
```
response = baseline_response * attention_gain
```

**竞争选择**:
```
winner = argmax(activation_i - inhibition_i)
```
